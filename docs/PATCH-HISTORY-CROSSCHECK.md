## 비교 원칙

과거에 합의했던 기능을 빠짐없이 다시 열거해서 **현재 정적 조사 목록과 대조**한다. 목록에 없다고 최종 ZIP에 없다고 결론내리지 않는다. 반대로 과거 논의가 있었다고 최종 ZIP에 실제 구현됐다고 주장하지 않는다. ZIP의 JS/CSS·`PATCH-NOTES.md`를 직접 확인한 것, 이력만 있는 것, 순정에 통합된 것, 이후 폐기된 것을 각각 구분한다.

## 이미 분류된 항목: 중복 개인 패치로 만들지 않음

- 순정 6.2.2에 반영된 것으로 앞선 조사에서 분류한 **디시콘 가로 휠 onWheel**, 작성자 검색 결과 60초 캐시, 글자콘 감시자 정리, 댓글 수치 0↔1 및 재렌더링 처리.
- 이후 제외된 **Turnstile 개인 브리지**, 읽음 구분선 강제 제거, 디시콘 자동 전송. 구형 YouTube `iframe → URL → 1px → OG 카드` 복원은 최신 ZIP의 제거 기록을 우선.
- 과거 6.1.0 패치 CSS를 최신 버전에 일괄 덮어쓰지 않음. 순정 기능은 중복 구현하지 않음.

## 이 대조로 확정할 수 있는 결과

- **기존 39개 조사 목록에서 익명 닉네임 기능이 독립 항목으로 빠진 것은 명백하다.**
- X 정리, 최근 디시콘 응답 경합, 호버 차단, 댓글 두 입력창의 동시 유지, 새로고침 실패·중복·정지 조건, 스포일러 정확한 여백은 **기능 이름만으로 충분히 복원되지 않았다**.
- 위 항목이 최종 ZIP에 빠졌다고 결론내릴 수는 없다. **과거 기록은 누락을 찾는 단서**이고, 최종 ZIP 코드가 구현 확인의 근거다. 최종 ZIP 원본 바이트를 이번 대조에서 직접 열지 못했으므로 전수조사 완료로 표시하지 않는다.
