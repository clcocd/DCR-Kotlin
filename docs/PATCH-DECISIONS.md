# 6.2.2 개인 패치 채택 기준

이 문서는 **순정 6.2.2 전체를 Kotlin/JS로 전환한 뒤** 수행할 개인 패치 병합의 기준이다. 2026-10-21 프로젝트 대화의 최종 채택·제외 결정을 우선하고, 그 이전 작업 메모는 더 나중의 결정에 반하는 경우 사용하지 않는다.

## 1. 지금은 개인 패치 이식 단계가 아님

- 원본 6.2.2 기능 및 UI를 Kotlin으로 모두 옮기고 기능 동등성 검증을 마친 뒤에만 개인 패치 이식을 시작한다.
- 원본에 이미 있는 기능은 중복 이식하지 않는다.
- 이 문서는 **구현 완료 목록이 아니라 향후 이식 범위 기록**이다. 이식·검증·승인이 없는 패치를 병합하지 않는다.

## 2. 최종 이식 대상으로 기록된 개인 동작 (아직 미적용)

2026-10-21 프로젝트에서 정리된 개인 패치 목적을 보존한다. 해당 동작이 실제 6.2.2 순정에 이미 포함되어 있다면 중복 적용하지 않는다.

1. 새로고침 체감 보정(초기/복귀 요청, 주기, 오류 처리); 순정에서 바뀐 요청·취소·제한 동작은 유지.
2. YouTube 미리보기 통합 동작: iframe, 원본 링크, 1px 간격, OG 카드 및 본문 순서의 **단일 패치**. 여러 독립 패치로 중복 적용하지 않음.
3. X 게시물 미리보기 관련 개인 동작.
4. 본문 다크모드 색상, 일반 OG 카드, 표 보정.
5. 본문 10초 캐시.
6. 댓글·대댓글 입력 위치 및 초안 동작(아래 제외 항목 준수).
7. 익명 닉네임 표시 관련 개인 동작.
8. 최근 디시콘·호버 정보 동작.
9. 본문 및 iframe 여백 보정.
10. 로그인 박스 배치 보정.
11. NetworkError 상세 로그.
12. 디시 동영상 전체화면 다크모드 관련 보정(실제 동작 검증 전 확정 구현으로 간주하지 않음).

## 3. 제외/순정 유지 (무단 재이식 금지)

- **디시콘 패키지 가로 휠:** 6.2.2 순정 구현을 유지한다. 구형 document 캡처 방식 및 개인 `scrollLeft += deltaY` 패치 재이식 금지. 관련 PR #15는 2026-11-20 병합 없이 닫힘.
- **개인 Turnstile 브리지:** 6.2.1부터 순정 대응이 있다는 최종 판단을 기준으로, 별도 개인 구현을 이식하지 않음.
- 읽음 구분선 강제 제거: 순정 설정으로 제어하므로 별도 패치 금지.
- 디시콘 자동 전송: 최종 이식 범위에서 명시적으로 제외.
- 댓글 입력창의 빈 공간 클릭 동작: 2026-10-21 기준 이식 제외. 댓글 위치·초안과 혼동하지 않음.
- 원본 6.2.2에 포함된 글자콘 감시자 정리, 목록·댓글 재렌더링 개선, 기본 검색 캐시 등은 원본 기능으로 취급.

## 5. 병합 조건

개인 패치마다 **현재 Kotlin 구현과 순정 6.2.2 동작을 먼저 비교**한다. 실제 차이가 있는 수정만 단일 브랜치/PR로 옮기며, 동일 기능의 구형 패치와 테스트용 변형을 무조건 합치지 않는다. 테스트가 없는 부분을 성공으로 보고하지 않는다.
